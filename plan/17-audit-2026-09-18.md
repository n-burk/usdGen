Date: 2026-09-18. Scope: `libs/usdGenPomade/`, `plugin/usdGenPomade/`, `plugin/usdGenPomadeTools/`,
the pomade additions in `libs/usdGenSchema/schema.usda`, `usdGenShaders/resources/shaders/pomadeTube.glslfx`,

## Headline

The model layer is far ahead of everything that carries it to the stage or to the screen. The
committer serialises exactly one L1 tube, the scene index publishes exactly one tube mesh, and
picking, undo and hydrate are compiled but have no caller in the tool. Plan phases P0 through P3 are
substantially real; P4 exists in the model and in hand-authored examples but not in the committer,
the scene index, or the shader bindings.

## Dead, stubbed, or diverged

1. **The hierarchy never reaches the stage.** `PomadeSnapshotFromModel` (L`pomadeCommit.cpp:196-206`)
   pushes one entry, `tubeId = 0`, `level = 1`; `childIndex` is written as a literal and both delta
   arrays are always empty. The nested tubes in `examples\pomade-braid-hierarchy.usda` are
   script-authored, not committer output. `UsdGenTubeHierarchyAPI` is never applied.
2. **Ptex channels above 0 are hard-zero** (L`pomadeBake.cpp:204`), so a `Clump` wired to any level
   through the `firstChannel` selector the committer authors reads zeros.
3. **Three of fourteen "CUDA kernels" are CPU-only** (K6, K7, K14), declared so by measurement at
   T`testUsdGenPomadeKernels.cpp:344-357`. Six more device lanes are test-only: production
   L`pomadeModel.cpp` calls the CPU twins unconditionally. Only K3-classify, K4, K5, K11 and the P0
   test-tube tessellate ever launch in production.
4. **`PomadeLaunchRootSampleMesh`** (L`pomadeKernels.cu:1320`) has no production caller and no test.
5. **Three parity tests assert nothing**: `CheckK6Stub`, `CheckK7Stub` and `CheckK14Stub`
   (T`testUsdGenPomadeKernels.cpp:324,334,647`) contain a printf and a TODO. `CheckCudaParityHook` at
   `:665` only checks that `cudaGetDeviceCount` answers.
6. **Neither worker loop has a try/catch** (L`pomadeCommit.cpp:1383`, L`pomadeBake.cpp:522`),
   contradicting §3.4 and both headers: a real throw terminates the process.
7. **Dead flags**: `HierarchyTube::transientParent` and `persistent` (L`pomadeModel.h:315-317`) are
   written and never read; `showAmplifiedHair` (P`pomadeToolState.py:24`) is referenced nowhere; the
   shader's `selected`, `xray`, `xrayOpacity` and `regionShift` are never authored, because the index
   publishes an empty material parameter set (L`imaging\pomadeSceneIndex.cpp:122`).
8. **Bound but never called from the tool**: `Pomade_Pick` and `Pomade_Undo` have ctypes signatures at
   P`pomadeLib.py:344,148` and no call site. `PomadeHydrateModel` has no C ABI wrapper at all, so
   hydrate is exercised only by the T1 tests.
9. **`NoteSwapped`'s cleanup wake is unreachable** (L`pomadeBake.cpp:480-488` against the worker
   predicate at `:536`), so stale `.ptx` files survive until the next successful bake.
10. **Saved `usdGen:map:file` is an absolute path** (L`pomadeCommit.cpp:1269`), making a saved groom
    non-portable. `pomadeCommit.h:167-176` also tells callers to run `PomadeSaveGroomAndMaps` off the
    UI thread while it mutates the session layer stack.
11. **Systemic tube-0 limitation**: every §5.2 section and center operation except
    `Pomade_MoveTubeCenterCV` and `Pomade_SculptStroke`, plus all of §5.3 fill and `Pomade_RelaxCenter`,
    operate on the single primary tube. Child tubes cannot be section-edited or independently filled.
12. **Self-documented algorithm divergences**: K2 is not the Polthier-Schmies straightest geodesic,
    K3's inside test is not a winding number in the per-face tangent chart, G1's snap is brute force
    rather than a kd-tree, and mirror-X uses closest-point instead of the E-4 kNN.
13. **Stale header comments**: L`pomadeModel.h:1` and L`pomadeModel.cpp:1` still read
    "PomadeModel stub (P0)" across roughly four thousand lines.
14. **No test asserts `SkippedStale`**, a named P1 exit check, and none covers `PomadeSaveGroom`
    failure or rollback beyond the `.usda` rejection at T`testUsdGenPomadeCommit.cpp:499`.
