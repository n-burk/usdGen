## Common environment

Machine constants, exported once at the top of a session. Every section
re-exports `PXR_PLUGINPATH_NAME` and `LD_LIBRARY_PATH` explicitly (below) so
each section block is copy-pasteable on its own.

Two facts about the 26.08 toolchain shape every command here:

* `usdview`, `testusdview` and `usdrecord` are **Python scripts** in the
  OpenUSD install prefix (`$USD/bin/…`); their shebangs name the build
  machine's venv interpreter, so on any host they must be launched through an
  explicit interpreter: `"$PY" "$USD/bin/usdview" …`. `usdcat` is a native
  binary and runs on its own.
* Build-tree plugin resources carry the generated `LibraryPath`-bearing
  `plugInfo.json`; they must precede the source-tree copies on the plugin path.

```sh
# --- machine constants (export once per session) ---------------------------
# Run from the repository root, or set USDGEN_SRC to that root.
export GEN="${USDGEN_SRC:-$PWD}"
export USD="${USD:?Set USD to the OpenUSD 26.08 install prefix}"
export PY="${VENV:+$VENV/bin/python3}"
export PY="${PY:-python3}"

# --- sanity (run once; every section assumes it passes) ---------------------
test -x "$USD/bin/usdcat"
"$PY" -c 'import pxr; print(pxr.GetBuildVersion())'    # must print the 26.08 build version
"$USD/bin/usdcat" --version
```

## 3. MSAA / alpha-to-coverage quality (R-2)

**Status:** PENDING M7 runner. **Gate:** **R-2** (release criterion).

Sample alpha-to-coverage is on by default and only bites with a multisampled
AOV. Compare 1× vs 4× MSAA and A2C on/off on ~1 px strands at 1080p and 4K,
then compare against the `translucent` / OIT build.

The 26.08 toggles are the **real environment names** (verified against the
26.08 source):

* **MSAA** — `USDVIEW_ENABLE_MSAA` (`usdviewq/stageView.py:839-842`). Read at
  process start: `USDVIEW_ENABLE_MSAA=0` → no MSAA; `USDVIEW_ENABLE_MSAA=1`
  (default) → 4-sample backbuffer. Because it is read at startup, each A/B leg
  is a separate launch.
* **Alpha-to-coverage** — disabled by the `HDX_DISABLE_ALPHA_TO_COVERAGE`
  `TfDebug` symbol (`hdx/drawTargetTask.cpp:428`,
  `hdx/renderSetupTask.cpp:227`, `hdx/debugCodes.h:20`):
  `TF_DEBUG=HDX_DISABLE_ALPHA_TO_COVERAGE`. A2C is otherwise on for the default
  material tag.

Commands (G3; zoom until strands are ~1 px before each capture; M0 smoke uses
`$GEN/tests/scenes/scene_empty_groom.usda` in place of `FIX`):

```sh
export PXR_PLUGINPATH_NAME="$GEN/build/usd/usdGenSchema/resources:$GEN/build/usd/usdGenImaging/resources:$USD/plugin/usd"
export LD_LIBRARY_PATH="$USD/lib:$GEN/build"

export FIX="$GEN/bench/head100k.usda"
test -f "$FIX"
mkdir -p "$GEN/out/t4/§3/1080p" "$GEN/out/t4/§3/4k"

# 1080p legs (each is a separate usdview launch; the MSAA toggle is read at
# process start, stageView.py:839-842; A2C-off is a TfDebug symbol):
USDVIEW_ENABLE_MSAA=0 \
  "$PY" "$USD/bin/usdview" --renderer GL --viewportSize 1920 1080 "$FIX"     # 1× MSAA
USDVIEW_ENABLE_MSAA=1 \
  "$PY" "$USD/bin/usdview" --renderer GL --viewportSize 1920 1080 "$FIX"     # 4× MSAA, A2C on
USDVIEW_ENABLE_MSAA=1 TF_DEBUG=HDX_DISABLE_ALPHA_TO_COVERAGE \
  "$PY" "$USD/bin/usdview" --renderer GL --viewportSize 1920 1080 "$FIX"     # 4× MSAA, A2C off

# 4K legs: same three launches with --viewportSize 3840 2160

# Offscreen A/B record legs (usdrecord has no --viewportSize; -w sets width and
# height is computed from it). For the 1080p record leg use -w 1920:
TF_DEBUG=HDX_DISABLE_ALPHA_TO_COVERAGE \
  "$PY" "$USD/bin/usdrecord" -r GL -w 1920 -f 1 \
  "$FIX" "$GEN/out/t4/§3/record_1080p_noa2c_###.png"

# OIT / translucent half: the same G3 with the usdGenHairPreviewTranslucent
# terminal bound (an M7-runner fixture variant; the prototype's translucent
# material is plan/prototypes/storm-hair-look/hair_scene_mtlx2.usda):
"$PY" "$USD/bin/usdview" --renderer GL --viewportSize 1920 1080 \
  "$GEN/plan/prototypes/storm-hair-look/hair_scene_mtlx2.usda"
```

Do this at 1920×1080 **and** 3840×2160. Record which configuration reads
better.

Env vars: `PXR_PLUGINPATH_NAME`, `LD_LIBRARY_PATH` (as exported above);
`USDVIEW_ENABLE_MSAA=0|1`; `TF_DEBUG=HDX_DISABLE_ALPHA_TO_COVERAGE`.

Artefact to attach: A/B screenshots (A2C on/off × MSAA 1×/4×) at each
resolution under `out/t4/§3/`, the translucent/OIT screenshots, and one line
per resolution in `out/t4/§3/verdict.log` stating which reads better.

## 5. Metal / Vulkan under `HDST_ENABLE_HGI_RESOURCE_GENERATION=1` (R-3)

**Status:** PENDING M7 runner. **Gate:** **R-3** (the gate's registered section
in `plan/10` §6.5; §4 carries the AMD/Intel half).

`HDST_ENABLE_HGI_RESOURCE_GENERATION=1` (a real env setting,
`hdSt/codeGen.cpp:166,192`) forces the Hgi resource path even on GL and is
*mandatory* on Metal/Vulkan. Run the whole probe set with it set, to catch
interstage-block / naming differences before shipping to a Mac. The Hgi
backend in 26.08 is chosen by platform + env, not by a Hydra render delegate:
`_MakeNewPlatformDefaultHgi()` (`pxr/imaging/hgi/hgi.cpp:177-208`) defaults
Linux → `HgiGL`, macOS → `HgiMetal`; `HGI_ENABLE_VULKAN=1` (env setting,
`hgi/hgi.cpp:24`) overrides Linux to `HgiVulkan` and fails hard
(`TF_CODING_ERROR`) unless the OpenUSD build was made with
`-DPXR_ENABLE_VULKAN_SUPPORT=ON` (i.e. `build_usd.py --vulkan`). So the
Vulkan and Metal legs run through the stock **GL** render engine:
`usdrecord -r GL` on a `--vulkan` prefix renders on Vulkan, and `usdrecord
-r GL` on a macOS build renders on Metal.

**Dev-host caveat (this aarch64 box):** `$USD`
was built without `--vulkan` and is not a macOS build, so its prefix ships
`libusd_hgiGL.so` and `libusd_hgiInterop.so` but **no** `libusd_hgiVulkan.so`
/ `libusd_hgiMetal.so` — `HGI_ENABLE_VULKAN=1` would hit the
`TF_CODING_ERROR` above. On the dev host run only the GL leg (Leg 1); it still
exercises the usdGen interstage blocks under forced Hgi resource
generation. Legs 2 and 3 run on a workstation with the matching OpenUSD
build (Vulkan: Linux + `--vulkan` prefix; Metal: macOS + Metal-support
prefix).

Common (re-exported per block so each leg is copy-pasteable on its own):

```sh

export LD_LIBRARY_PATH="$USD/lib:$GEN/build"

export FIX="$GEN/bench/head100k.usda"                 # M0 smoke: $GEN/tests/scenes/scene_empty_groom.usda
test -f "$FIX"
mkdir -p "$GEN/out/t4/§5"
```
