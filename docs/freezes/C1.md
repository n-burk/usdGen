# C1 freeze — `usdGen:` property registry (M1)

Contract C1 (plan/design/adr-v1.md §3): *"the `usdGen:` property names and the
prim type names"*, frozen at the end of M1. Normative source:
`plan/02-schema.md` §1–§2 and §6 (ADR §9 R7 — the single property registry).
Authoritative implementation: `libs/usdGenSchema/schema.usda` (the codeless
domain); checked-in generated resources:
`plugin/usdGenSchema/resources/{generatedSchema.usda, plugInfo.json}`.
The executable check is `tests/testUsdGenContracts.cpp` (T1), which compares
the literal lists below against the live `UsdPrimDefinition`/`UsdSchemaRegistry`.

Status: **FROZEN at M1.** Any rename / retyping / default change / token-set
change of an entry below is a C1 break and requires a new contract version,
not an M1 edit (02 §8.1/§8.5: deprecate, never remove in place).

Dirty-class vocabulary (02 §2.1): **structural** (graph digest term;
recompile), **structural(topology)** (curve/CV/published-prim count;
re-allocate, no digest), **capture** (re-`Capture()` node+downstream),
**value** (per-frame parameter), **toggle** (`usdGen:enabled` on
topology-preserving operators), **publication** (imaging-only re-emit),
*cosmetic* (never routed).

Concrete: `UsdGenGroom`, `UsdGenDescription`, `UsdGenGuideSet`,
`UsdGenScatter`, `UsdGenGrow`, `UsdGenGuideInterpolate`, `UsdGenCurveSource`,
`UsdGenClump`, `UsdGenNoise`, `UsdGenLength`, `UsdGenWidth`, `UsdGenDirection`,
`UsdGenSmooth`, `UsdGenResample`, `UsdGenScale`, `UsdGenCurl`, `UsdGenBend`,
`UsdGenStraighten`, `UsdGenDisplace`, `UsdGenWave`, `UsdGenPart`,
`UsdGenExprOp`, `UsdGenSculptLayer`, `UsdGenDeform`, `UsdGenCollide`,
`UsdGenWind`, `UsdGenFreeze`, `UsdGenInstance`, `UsdGenImageMap`,
`UsdGenPtexMap`, `UsdGenExprMap`, `UsdGenPaintMap`, `UsdGenNoiseMap`,
`UsdGenCombineMap`, `UsdGenGuideProximityMap`.

Abstract: `UsdGenOperator`, `UsdGenGenerator`, `UsdGenStyler`,
`UsdGenDeformer`, `UsdGenMap`.

API schemas (single-apply): `UsdGenMaskAPI` (auto-applied to
`UsdGenOperator`), `UsdGenLookAPI`, `UsdGenRestAPI`, `UsdGenCurveAPI`.

Bases: `UsdGenGroom : UsdGeomImageable`, `UsdGenDescription :
UsdGeomBoundable` (implementsComputeExtent), `UsdGenGuideSet :
UsdGeomImageable`, `UsdGenOperator : UsdTyped`; generators inherit
`UsdGenGenerator`, v1/v2 stylers inherit `UsdGenStyler` (`UsdGenSculptLayer`
too), deformers inherit `UsdGenDeformer`, map subtypes inherit `UsdGenMap`,
API schemas inherit `UsdAPISchemaBase`.
