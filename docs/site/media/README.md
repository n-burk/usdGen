`ui/pomade-*.png` usdview screenshots in this directory are usdGen project
media under the repository's MIT license. Their scenes and capture scripts
are linked from `docs/reference/media.json` and `docs/reference/ui.json`.

`stoat-detail.png`, and `ui/alab-*.png` show images derived from the
separately licensed ALab stoat character. **These images are subject to the ASWF Digital Assets

[preparation and groom guide](../../../examples/alab/README.md) records the
source URLs and exact asset changes. These images show the locally generated
guide-driven usdGen study: the consolidated character uses `render_high`
geometry and skeleton, the missing outfit ambient-occlusion map is replaced

fits a smooth tail scalp, and adds generated coat curves. No affiliation or
